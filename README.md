# 🏥 Healthcare Management System Dashboard (Power BI)

## 📌 Project Overview

The **Healthcare Management System Dashboard** is a Power BI-based data analytics project designed to analyze healthcare data and generate meaningful insights. The dashboard helps in understanding patient information, hospital performance, revenue trends, and operational efficiency through interactive visualizations.

## 🎯 Objectives

* Analyze healthcare data to identify important trends and patterns
* Monitor patient-related insights
* Track hospital performance using key metrics
* Create interactive dashboards for better decision-making

## 🛠️ Tools & Technologies Used

* **Power BI** – Data visualization and dashboard creation
* **Microsoft Excel / CSV** – Data handling and preprocessing
* **Power Query** – Data cleaning and transformation
* **DAX** – Creating calculated measures and KPIs

## 📊 Dashboard Features

### 👨‍⚕️ Patient Analysis

* Total number of patients
* Patient distribution analysis
* Patient demographic insights

### 🏥 Hospital Performance

* Department-wise analysis
* Service performance tracking
* Operational insights

### 💰 Revenue Analysis

* Revenue trends
* Category-wise revenue analysis
* Financial performance insights

### 📈 Key Performance Indicators (KPIs)

* Total Patients
* Total Revenue
* Average Metrics
* Performance Indicators

## 🔍 Key Insights

* Identified important healthcare trends using interactive charts
* Analyzed patient and hospital performance data
* Created a user-friendly dashboard for quick decision-making
